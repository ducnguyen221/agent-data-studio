# pbi-done — adapter quy trình

Đọc toàn bộ [quy trình gốc](../../../commands/pbi-done.md) trong repo trước khi làm. Thay `$ARGUMENTS` bằng nội dung người dùng cung cấp; nếu thiếu mục tiêu thì hỏi ngắn gọn. Đọc skill và workflow được dẫn tới trực tiếp từ repo; không lấy bản cache hoặc bản trong trạm. Nếu file gốc không mở được, báo thiếu source và dừng quy trình này.
