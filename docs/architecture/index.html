Bên trong
Agent Data Studio.

Một MCP server nhỏ có chính sách ở tầng server, bộ skill là nguồn sự thật duy nhất, dữ liệu và tri thức nằm ở trạm ngoài Git, mọi khâu có cổng kiểm chạy được. Trang này dành cho BI developer, IT bảo mật và người muốn tuỳ biến hoặc đóng góp.

Tổng thể

Các khối và đường nối

Host gọi MCP server qua stdio. Server nói chuyện với ba đích Power BI, ghi hồ sơ vào trạm dữ liệu, và áp chính sách cho mọi truy vấn DAX đi qua nó.

An toàn dữ liệu

Chính sách ở tầng server

Mọi câu DAX gửi qua execute_dax_local / execute_dax_service đi qua năm bước. Nguồn: powerbi_agent/policy.py.

  1. 1

    Aggregate-only

    Mặc định bật (tắt: POWERBI_AGGREGATE_ONLY=0). Chặn EVALUATE 'Bảng', EVALUATE Bảng, EVALUATE ALL(…) / ALLNOBLANKROW(…); trả gợi ý viết lại bằng SUMMARIZECOLUMNS, GROUPBY, TOPN hoặc measure.

  2. 2

    PII blocklist

    policy.json ở trạm (hoặc POWERBI_POLICY_FILE, bắt buộc ngoài repo); mẫu policy.example.json. Bảo thủ: tên cột xuất hiện bất kỳ đâu trong DAX là chặn. File hỏng thì chặn luôn.

  3. 3

    Engine chạy

    Desktop qua ADOMD.NET, Service qua REST. Dữ liệu được tính trong engine Power BI; chỉ kết quả trả về.

  4. 4

    Row cap

    Kết quả có cột dạng chữ (dimension) bị siết còn 200 dòng (POWERBI_DIMENSION_ROW_CAP); kết quả thuần số giữ trần chung POWERBI_MAX_ROWS (mặc định 1000).

  5. 5

    Audit JSONL

    audit/YYYY-MM.jsonl ở gốc thư mục dự án (đổi qua POWERBI_AUDIT_DIR). Mỗi dòng: ts · tool · verdict · rows · query_sha256 — lưu băm, không lưu nguyên câu DAX. Lỗi ghi audit không làm hỏng truy vấn.

Trung thực về giới hạn: đây là lưới chống rò rỉ do sơ ý (agent tiện tay kéo nguyên bảng), phân tích DAX theo kiểu best-effort. Bảo mật cứng vẫn là RLS trên model và service principal quyền tối thiểu. Audit log mặc định nằm trong trạm; chưa thiết lập trạm thì lùi về thư mục tạm của hệ điều hành, không bao giờ vào repo.

Giới hạn

Giới hạn kỹ thuật & việc còn lại

Biết trước khi dùng

  • Windows-only cho Desktop — Power BI Desktop chỉ có trên Windows.
  • Agent không thấy render — nghiệm thu mắt là cổng bắt buộc của người dùng.
  • Policy là phân tích DAX best-effort — chống sơ ý, không thay RLS.
  • Bookmark không tự động hoá — clone bookmark từng làm vỡ báo cáo thật.
  • Ghi PBIR cần file đóng — ràng buộc của định dạng; công cụ tự nhắc.
  • Chưa nghiệm thu: Power BI Service, pbi-publish, Python 3.14 với Desktop thật.
  • powerbi-modeling-mcp còn Public Preview — pin version, theo dõi release notes.
