1 Bước 01 / Dán yêu cầu

Dán yêu cầu này vào ứng dụng AI của bạn

Mở ứng dụng AI trên máy Windows, bấm Sao chép rồi dán nguyên văn. Agent đọc hướng dẫn cài dành cho agent và tự nhận ra mình là ứng dụng nào để đăng ký cho đúng.

Yêu cầu cài đặt · dùng cho mọi ứng dụng AI
Hãy cài Agent Data Studio lên máy Windows này cho chính ứng dụng AI bạn đang chạy
(Codex, Claude Code, Claude Desktop hoặc Google Antigravity).

Nguồn duy nhất: https://github.com/ducnguyen221/agent-data-studio
Đọc trước hướng dẫn dành cho agent tại
https://raw.githubusercontent.com/ducnguyen221/agent-data-studio/main/INSTALL.md
(không mở được link thì clone repo rồi đọc file INSTALL.md trong đó),
rồi làm đúng và đủ các bước trong đó: kiểm tra máy đã có gì (Git, Python, PowerShell),
hỏi tôi trước khi cài thêm phần mềm hoặc cần quyền admin, clone repo về thư mục an toàn
(không OneDrive/Desktop), chạy install.ps1 cho đúng host đang dùng, chạy doctor.ps1,
hướng dẫn tôi khởi động lại ứng dụng, rồi kiểm tra bằng bài mẫu samples/sales-demo.csv.

Quy tắc: chỉ chạy script/lệnh có trong repo trên hoặc trong INSTALL.md; không đổi chính sách
hệ thống; không đọc hay ghi mật khẩu/khóa; gặp lỗi thì dừng và giải thích bằng lời thường.
Kết thúc bằng bản tóm tắt: đường dẫn repo, host đã đăng ký, kết quả doctor từng dòng,
phần mềm đã cài thêm, và việc tôi cần làm tiếp.
Install prompt · works in any AI app
Install Agent Data Studio on this Windows machine for the AI app you are running in
(Codex, Claude Code, Claude Desktop or Google Antigravity).

Single source: https://github.com/ducnguyen221/agent-data-studio
First read the agent guide at
https://raw.githubusercontent.com/ducnguyen221/agent-data-studio/main/INSTALL.md
(if the link cannot be opened, clone the repo and read its INSTALL.md),
then follow every step in it: check what the machine already has (Git, Python, PowerShell),
ask me before installing software or anything that needs admin rights, clone the repo to a
safe folder (not OneDrive/Desktop), run install.ps1 for the host in use, run doctor.ps1,
tell me how to restart the app, then verify with the sample samples/sales-demo.csv.

Rules: only run scripts/commands from that repo or INSTALL.md; do not change system policy;
never read or write passwords/keys; on any error stop and explain in plain words.
Finish with a summary: repo path, registered host, every doctor line, software added,
and what I need to do next.
  1. Kiểm tra máy đã có Git, Python, PowerShell — chỉ đọc, chưa cài gì.
  2. Trình kế hoạch ngắn và chờ bạn đồng ý trước khi cài thêm phần mềm.
  3. Lấy repo về %USERPROFILE%\agent-data-studio, không đặt trong OneDrive hay Desktop.
  4. Chạy trình cài cho đúng ứng dụng bạn dùng, rồi chạy doctor và chép lại từng dòng kết quả.
  5. Hướng dẫn bạn khởi động lại ứng dụng và thử với dữ liệu mẫu.

Tab chat của Claude Desktop không chạy được lệnh trên máy. Hãy dán yêu cầu vào Claude Code, Codex hoặc Antigravity và nói thêm “cài cho Claude Desktop”, hoặc tự cài theo mục cuối.

Kiểm tra: Agent trả lời bằng một kế hoạch và hỏi bạn trước khi cài thêm bất cứ thứ gì.
2 Bước 02 / Đồng ý phần cần cài

Agent hỏi trước khi cài thêm phần mềm

Tối thiểu máy cần Git và Python. Power BI Desktop và các thư viện đi kèm chỉ cần khi bạn làm với báo cáo; bài thử đầu tiên chưa cần. Không cần SQL Server hay SSAS server. Bảng dưới là những gì agent có thể đề nghị cài — bạn đồng ý từng mục.

Thành phầnKhi nào cầnGói wingetCần admin?

Chỉ chạy khi bạn đồng ý · PowerShell
winget install --id Git.Git -e --scope user
winget install --id Python.Python.3.12 -e --scope user
winget install --id 9NTXR16HNW1T --source msstore

Máy không có winget (Windows LTSC, Windows Sandbox): tải từ trang chính thức — Git, Python (chọn 3.12 hoặc 3.13, tick “Add python.exe to PATH”), Power BI Desktop từ Microsoft Store hoặc trang tải của Microsoft. Python 3.14 mới được kiểm bằng bộ test, chưa kiểm kết nối Power BI Desktop thật.

Dòng cuối là Power BI Desktop, có thể cài sau. Script của repo chạy bằng -ExecutionPolicy Bypass cho riêng lệnh đó; agent không đổi chính sách của máy. Nếu tổ chức chặn script, hãy nhờ IT.

agent-data-studio/Mã nguồn, engine, scripts, skills. Cập nhật tại đây.
workspace/Projects, knowledge, outputs và state cá nhân. Git bỏ qua toàn bộ.

Đã có trạm dữ liệu riêng? Nói với agent đường dẫn đó trước khi cài để nó đặt ADS_DATA. Chế độ mặc định dùng workspace/.

Kiểm tra: Bạn biết agent sẽ cài gì, ở đâu, và đã đồng ý.
3 Bước 03 / Khởi động lại

Mở lại ứng dụng AI trong chính repo

Phiên đang dùng để cài chưa thấy công cụ mới — điều đó bình thường. Khởi động lại theo bảng, rồi hỏi trong phiên mới: “Gọi knowledge_status, rồi đọc skills/data-discovery/SKILL.md trong repo này.”

Ứng dụngAgent cài vớiKhởi động lại và xác nhận
Codex-Hosts codexMở lại trong thư mục repo; bản desktop mở repo làm project và tin cậy thư mục.
Claude Code-Hosts claudeMở lại trong thư mục repo; xem /mcp hoặc claude mcp list.
Claude Desktop-Hosts claude-desktopThoát hẳn từ khay hệ thống rồi mở lại. Chỉ có 16 công cụ MCP, không có skill.
Antigravity-Hosts antigravityKhởi động lại, mở thư mục repo, xem mục MCP.

Agent chép lại từng dòng của doctor.ps1. Dòng NOT_CHECKED ở kết nối Power BI không phải lỗi: khi đã mở một báo cáo trong Power BI Desktop, nhờ agent chạy thêm doctor với -ProbeDesktop để thử EVALUATE ROW("x",1).

Kiểm tra: Phiên mới thấy công cụ của repo và doctor không còn dòng FAIL. Chưa đạt hai điều này thì xem là chưa cài xong trên ứng dụng đó.
4 Bước 04 / Làm việc đầu tiên

Thử với dữ liệu mẫu, rồi nối Power BI

Agent thường đã làm bài mẫu ở cuối lượt cài. Muốn tự thử lại, gửi yêu cầu dưới đây. Kết quả nằm trong workspace/outputs/, không đưa vào Git; con số đúng là 182 đơn, 20.350.000 VND.

Yêu cầu đầu tiên
Trong repo này, đọc skills/data-discovery/SKILL.md
và samples/sales-demo.csv. Hãy tóm tắt bộ dữ liệu,
đề xuất 3 câu hỏi kinh doanh, kiểm tra tổng số đơn
và doanh thu, rồi lưu ghi chú vào workspace/outputs/.

Với Power BI, mở tệp .pbix trước rồi hỏi: “Liệt kê các model đang mở và các bảng của model; chưa chỉnh sửa gì.”

Hoàn tất: AI tạo được ghi chú mẫu với đúng con số và bạn biết kết quả nằm ở đâu.
Tự cài không cần agent

Ba lệnh trong PowerShell

Cài Git và Python như bảng ở bước 02, mở PowerShell mới rồi chạy. Thay codex bằng claude, claude-desktop hoặc antigravity theo ứng dụng bạn dùng.

Cài tay · PowerShell
git clone https://github.com/ducnguyen221/agent-data-studio "$env:USERPROFILE\agent-data-studio"
cd "$env:USERPROFILE\agent-data-studio"
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -Hosts codex

Muốn kiểm máy trước khi cài: chạy .\doctor.ps1 -Preflight theo cùng cách sau lệnh cd. Lệnh in 7 dòng prereq (PowerShell, ExecutionPolicy, Git, Python, ADOMD.NET, Node, az), chưa cần .venv, và thoát mã 1 nếu có dòng FAIL. Cài nhiều ứng dụng một lần: -Hosts codex,claude; doctor và uninstall thì mỗi lần một ứng dụng.

Cài xong, chạy .\doctor.ps1 -Hosts codex theo cùng cách và khởi động lại ứng dụng như bảng ở bước 03. MCP được gộp vào cấu hình người dùng của ứng dụng, nên mọi thư mục mở trong ứng dụng dùng chung server của checkout này: mỗi máy trỏ một checkout. Xem giới hạn

Khi cần trợ giúp

Bốn chỗ nên kiểm tra trước

AI không thấy công cụ

Khởi động lại ứng dụng theo bảng ở bước 03 và mở đúng thư mục repo. Vẫn chưa thấy thì nhờ agent chạy lại trình cài cho đúng ứng dụng.

Power BI chưa kết nối

Kiểm tra báo cáo đang mở trong Power BI Desktop và thư viện ADOMD.NET, rồi chạy .\doctor.ps1 -ProbeDesktop. Việc phân tích CSV mẫu vẫn làm được trước.

Script bị chặn

Nếu cả lệnh có -ExecutionPolicy Bypass cũng bị chặn, đó là chính sách của tổ chức. Nhờ IT, không tự vượt.

Agent muốn làm việc lạ

Đổi chính sách máy, đọc mật khẩu, tải script từ nơi khác repo: từ chối và yêu cầu agent quay lại hướng dẫn trong repo.
