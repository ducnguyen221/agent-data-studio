Mở repo. Chạy cài đặt.
Bắt đầu làm việc.

Bạn cần một máy Windows, một AI host và thư mục repo này. Mọi kỹ năng và công cụ chạy từ repo; dữ liệu của bạn nằm trong workspace/ ở cùng chỗ. Hãy đi theo bốn bước dưới đây.

Bước 01 / Chuẩn bị

Chọn một chỗ lưu repo trên máy

Cài Git, Python 3.11+ và một trong ba ứng dụng AI: Codex, Claude Code hoặc Antigravity. Power BI Desktop cần khi bạn muốn làm việc với báo cáo đang mở; bạn vẫn có thể bắt đầu từ tệp CSV mẫu trước.

agent-data-studio/Mã nguồn, engine, scripts, skills. Cập nhật tại đây.
workspace/Projects, knowledge, outputs và state cá nhân. Git bỏ qua toàn bộ.

Đã có trạm dữ liệu riêng? Có thể đặt ADS_DATA tới thư mục ngoài repo trước khi cài. Chế độ mặc định dùng workspace/.

Kiểm tra: Bạn biết mình muốn đặt repo ở thư mục nào và đã mở Codex trên Windows.
Bước 02 / Nhờ Codex cài

Dán yêu cầu này vào Codex

Codex sẽ lấy repo, đọc trình cài rồi cài ngay tại folder đó. Installer mặc định cấu hình Codex. Có thể chọn thêm Claude Code hoặc Antigravity bằng -Hosts claude,codex,antigravity; hãy kiểm tra từng host trên máy bạn sau khi cài.

Yêu cầu cho Codex
Hãy cài Agent Data Studio trên máy Windows này.
Clone https://github.com/ducnguyen221/agent-data-studio
vào thư mục source phù hợp trên máy tôi. Mở repo đó,
đọc README và install.ps1 trước khi chạy. Dùng chế độ
workspace mặc định trong repo, cài cho Codex, rồi kiểm
tra kết quả. Cho tôi biết đường dẫn repo, trạng thái MCP
và việc đầu tiên tôi có thể thử với samples/sales-demo.csv.

Dùng Claude Code hoặc Antigravity? Nhắc Codex chạy installer với -Hosts tương ứng. Repo có adapter skill cho các host; nội dung gốc nằm tại skills/. Khả năng tự nạp adapter cần được kiểm tra trong phiên host thực tế.

MCP được gộp vào cấu hình người dùng của host (ví dụ ~/.codex/config.toml) cạnh các server sẵn có, nên mọi thư mục mở trong host dùng chung server của checkout này: mỗi máy trỏ một checkout. Muốn chuyển sang checkout khác, chạy .\uninstall.ps1 -Hosts <host> ở checkout cũ trước. Xem giới hạn

Kiểm tra: Repo có workspace/, môi trường Python và host được đăng ký thành công.
Bước 03 / Kiểm tra

Khởi động lại AI trong chính repo

Đóng và mở lại AI host ở folder agent-data-studio. Yêu cầu AI kiểm tra kết nối MCP và đọc skill data-discovery từ repo. Nếu host chưa nhận công cụ, chạy lại installer cho đúng host và xem thông báo lỗi cụ thể.

Có thể nhờ AI chạy .\doctor.ps1 -Hosts codex trong PowerShell trước. Doctor kiểm môi trường và đăng ký MCP; kết quả NOT_CHECKED vẫn cần bạn xác nhận trong host và Power BI thật. Nếu máy tổ chức chặn script, hãy nhờ IT cho phép theo chính sách của tổ chức.

Khi đã mở một báo cáo trong Power BI Desktop, chạy thêm .\doctor.ps1 -ProbeDesktop để thử kết nối bằng EVALUATE ROW("x",1). Nếu Desktop đang đóng, kết quả là NOT_CHECKED (chưa kiểm), không phải lỗi.

  1. Codex: mở repo làm project, kiểm tra MCP và skill trong .agents/skills/.
  2. Claude Code: mở repo, kiểm tra MCP và adapter trong .claude/skills/.
  3. Antigravity: mở repo, kiểm tra MCP và adapter trong .agents/skills/.
Kiểm tra: AI chỉ ra được đường dẫn skills/data-discovery/SKILL.md và thấy công cụ MCP của repo. Nếu một host chưa nhận, xem là chưa cài xong trên host đó.
HostTrình càiBước xác nhận trên máy bạn
CodexMặc địnhMở repo, xác nhận skill và MCP được nạp.
Claude CodeChọn qua -HostsMở repo, xác nhận skill và MCP được nạp.
AntigravityChọn qua -HostsMở repo, xác nhận skill và MCP được nạp.

Bảng này mô tả đường cài đặt hiện có; kiểm thử thực tế trên cả ba host cho bản đóng gói hiện tại đang được hoàn tất.

Bước 04 / Làm việc đầu tiên

Thử với dữ liệu mẫu, rồi nối Power BI

Bắt đầu với dữ liệu giả lập đi kèm repo. Kết quả được lưu trong workspace/outputs/, không đưa vào Git. Sau đó mở một báo cáo Power BI Desktop và nhờ AI liệt kê model trước khi yêu cầu chỉnh sửa.

Yêu cầu đầu tiên
Trong repo này, đọc skills/data-discovery/SKILL.md
và samples/sales-demo.csv. Hãy tóm tắt bộ dữ liệu,
đề xuất 3 câu hỏi kinh doanh, kiểm tra tổng số đơn
và doanh thu, rồi lưu ghi chú vào workspace/outputs/.

Với Power BI, mở tệp .pbix trước rồi hỏi: “Liệt kê các model đang mở và các bảng của model; chưa chỉnh sửa gì.”

Hoàn tất: AI tạo được ghi chú mẫu và bạn biết kết quả nằm ở đâu.
Khi cần trợ giúp

Ba chỗ nên kiểm tra trước

AI không thấy skill

Mở AI tại folder repo, khởi động lại host, rồi kiểm tra .agents/skills/ hoặc .claude/skills/.

Power BI chưa kết nối

Kiểm tra báo cáo đang mở trong Power BI Desktop và thư viện ADOMD.NET, rồi chạy .\doctor.ps1 -ProbeDesktop. Việc phân tích CSV mẫu vẫn có thể làm trước.
